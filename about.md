# Supleq Smart Clicks

Dedicated Up Arrow and Spacebar sounds recorded by Supleq.

- Normal Up Arrow: random real-world click + release samples.
- Fast Up Arrow: automatically switches to more aggressive fast-spam samples when a rolling press rate exceeds 8 CPS (adjustable).
- Spacebar: its own separate recorded click + release samples.
- Never play the same sample twice in a row within one sound category.
- Only plays during unpaused gameplay. Key autorepeat is ignored.
- All samples load into memory once, as short PCM WAVs, for low playback latency.
- Volume and spam threshold customizable in the Geode mod settings.

**Note:** This is a source project. Build it to obtain the installable `.geode` file.
